## 这个站如何更新？

```text
GitHub 网页编辑 docs/*.md（也支持本地 Git 提交）
        ↓
提交修改到 main
        ↓
自托管服务检查新提交并运行 MkDocs
        ↓
自有网站切换新版本（本次演示：127.0.0.1:8765）
```

先阅读[快速开始](getting-started.md)，也可以查看[更新日志](changelog.md)。

!!! note "演示范围"
    自动发布的是你提交的文档，不会自动替你编写或核实内容。
